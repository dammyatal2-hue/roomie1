
# Roomie

Roommate matching, rental listings, booking requests, community, and messaging built with React and Supabase.

  ## Running the code

1. Run `npm install`.
2. Create a Supabase project.
3. Run `supabase/migrations/202607220001_initial_schema.sql` in the Supabase SQL editor.
4. Copy `.env.example` to `.env.local` and add the project URL and anon key.
5. Enable email authentication in Supabase. If desired, configure Google OAuth and add the local/production redirect URLs.

Run `npm run dev` to start the development server or `npm run build` for a production build.
